# HR 常见问题

1. 期望薪资
要符合公司对你的评级以及公司的预算，不要过高过低，建议去 offer show 上先找公司对应岗位的开发薪资，没有的话去牛客网上查找是否有该公司的 offer 信息，建议薪资范围给一个底线。
参考话术：
我的期望薪资在 xxk 左右。
因为我目前手里的 offer 薪资大概在 xxk 左右，我目前期望的话也希望能够和这个薪资持平或者更高。from 张爱真

2. 工作地点
可以以面试公司的 base 地为主，如果该公司有多个 base 地，可以参考如下话术：
我对工作的城市要求不是很高，个人可能比较想尝试在一线或新一线城市发展（这么说可选择的余地很多，如果公司连这些城市都覆盖不到说明公司规模太小）。from 张爱真

3. 入职时间
一般问了这个问题有两种情况，需要提前实习或者了解你毕业之后多久可以入职，根据自身情况回答，参考话术：
第一种情况：我这边面试通过之后一周之内就可以入职，学校这边也比较鼓励我们出去实习，我自己也想提前适应工作节奏。from 张爱真
第二种情况：我是六月末毕业，毕业之后我这边就可以入职了。

4. 平时的爱好

5. 学习方式
专业课学习：C 语言、C++、计算机网络等。
课后自主学习：自己扩展技术栈，如 C++ 新特性、QT、异步编程等。
实验室项目研发（实习项目研发）：项目相关技术栈。
可以展示自己的笔记。

6. 项目的完成背景
简要介绍项目（HR 听不懂），怎么接触到项目并参与进来，充当的角色。

7. 是否可以提前实习
建议是可以参加实习，实习时间到毕业答辩前。

8. 在项目中充当的角色
觉得自己可以的，建议说组长，负责统筹和项目实现。

9. 项目的分工
基于你是组长的角色，可能会有这个问题。（可以私聊我问下，打字好多，from zaz）

10. 手头 offer
建议说两个，比较牛 x 的同学可以多说几个，注意公司规模要和面试的差不多或较小一些，注意薪资，base 地等公司信息。

11. 未来三到五年职业规划
未来一年完成从学生到从业者的转变，能够快速融入团队，完成领导交代给我的任务。
未来两到三年内成为团队技术核心，能够独立完成项目。
三到五年内在提升自己技术的同时提高自己的职位评级。
from 万能榮

12. 还在面试的原因
因为是自己毕业后的第一份工作，想谨慎选择工作单位，进行一些横向比较，所以现阶段还在面试。from 张爱真

13. 是否接受转语言
接受，自己学习能力强，也愿意学习新的知识。

14. 自己的优缺点
缺点也别是真的缺点，不知道咋说的可以在这评论。

18. 之前是否实习过/之前没实习的原因是什么
如果你是应届生，可以选择说在实验室参与项目研发，实验室是校企合作的，你作为组长参与较多，所以没有参加实习。
如果你是非应届生，可以说明简历中的项目是在实习公司完成的。

by 张爱真
