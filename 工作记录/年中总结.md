一、业绩目标达成

1. 系统功能升级

  1.1 merger3 支持新接口以及旧接口的改造，包括新支持 yrec.list/recall，ug.coupon_rank，改造 rec.list 和 otd.product 支持 ListEntity，search.recall 接 DX 等。
  1.2 merger3 搜索相关性链路升级，包括精排支持 Bert+LGB 链路调用，粗排支持图搜相似分计算、请求 img_ocr 解析、精排限流等。
  1.3 merger3 支持各接口协议的更新及透传，包括 Context 曝光序列、图搜、ListWise、Mixer 等协议的更新。
  1.4 merger3 支持链路透明化监控上报，包括 QPS、耗时、打分、候选等，监控打分率细化到 item 粒度，提升问题排查效率。
  1.5 merger3 近线召回、影子精排等 merger 资源申请以及线上联调。
  1.5 协助搭建 FeatureStore 框架及上线联调。

2. 性能与稳定性优化

  2.1 merger3 查询树删除 L0 部分代码，支持缓存 + 并行优化，优化后耗时下降 50%。
  2.2 创意召回关闭 cache 使用 RocksDB LRU，内存使用减少 80%，大流量耗时下降约 1.2ms。
  2.3 宏替换 merger3 重复代码，减少 1k 各场景重复代码。
  2.4 merger3 线上 Appcfg 无用配置清理，脚本校验优化。
  2.5 过滤 IST、UPT、CompareV 请求不落盘 MergerLog。

3. 排查线上问题以及 merger3 客服答疑

  3.1 排查透明化链路上报监控数量不一致问题，dragonfly 和 m3 在上报聚合时的候选数量差异问题等。
  3.2 排查 merger3.search 实验参数不生效问题。
  3.3 和搜推对齐打分率差异问题，优化了打分率上报粒度，支持多模型分开上报。
  3.4 整理 merger3 目前的 kafka 配置、关键监控、扶持逻辑等文档供上游查询以及 merger 和 FeatureStore 逻辑对接。
  3.5 新接口配置 unific 和新增 dispatcher 等问题答疑。
  3.6 配合数据和机制工程同学解析 MergerLog，并新增 MergerLog 单独上报全量 item 供算法使用。
  3.7 帮助前端同学解析 hub 响应报文并讲解。

4. 参与大促值班及容灾演练。

二、专业技能提升

1. 熟悉使用基础库，例如使用 oxygen 完成对 Json 文件的解析，使用 carbon 完成对字符串的处理等工作。
2. 学习使用内存检测工具，例如使用 jeperof 检测 merger3.search 接口内存异常上涨问题。
3. 进一步使用了 C++11、C++17 新特性，提高代码效率和可维护性。
4. 提升代码规范性，严格按照 C++ 代码规范完成开发。

三、不足与反思

1. 部分开发工作暴露出细节严谨性待提升的问题，如接口协议改造时偶发边界条件遗漏、配置参数疏忽等粗心现象，反映出编码阶段的全局校验意识不足，后续也会针对这个问题进行改正。
2. 沟通效率待提升，如需求理解不透彻导致影响到开发联调效率等问题，下半年提升需求理解能力，减少无效沟通，达到快速高效的沟通效果。
3. 业务理解不透彻，对于 merger 与其他服务的交互理解还需要进一步加强。

四、总结

  对于 2025 年上半年的工作，主要完成了在 merger3 部分核心聚焦于系统功能升级，成功支持了多个新接口（如 yrec.list/recall, ug.coupon_rank）的接入，并对关键旧接口（rec.list, otd.product, search.recall）进行了面向 ListEntity 等新要求的改造与 DX 接入。同时，搜索相关性链路实现了重要升级，精排引入 Bert+LGB 模型，粗排增强图搜相似分计算与 img_ocr 解析能力，并实施了精排限流等稳定性措施。在性能与稳定性优化方面，通过重构查询树、优化缓存策略（如创意召回使用 RocksDB LRU）以及宏替换大幅精简重复代码，显著提升了系统效率和可维护性。在排查线上问题方面，高效定位并解决了实验参数不生效、监控上报差异、打分率不一致等关键问题，积极进行新接口配置答疑，并推动 TessDoc 的使用。

  在自己上半年的工作中，自己也意识到自己的一些不足，如对于代码实现的严谨性、边界条件的考虑还不够全面，例如 merger 在多模型执行时可能会出现的一些问题考虑的还不够全面。下半年自己还要加强对于 merger 代码的理解，对于开发过程中可能出现的问题列出 ToDo List，提交前进行检查，避免上线后出现问题。

  展望下半年，希望在巩固上半年成果的基础上，着力提升代码质量与严谨性，加强自测与边界覆盖。深化业务理解，系统学习 merger3 在整体架构中的角色与协同机制，包括进一步学习 merger 与上下游服务的交互机制和设计。优化沟通协作，确保需求理解精准到位，提升沟通效率。并持续推进系统优化与创新，保障 merger3 系统的高性能、高可用性，更好地支撑业务发展目标。
